EMU3 Disk Manager - Help

Quick reference for managing E-MU Emulator III/IV disk images

Overview

EMU3 Disk Manager lets you mount one or more E-MU hard disk images, browse their folders, organize files, copy content between images, and export banks or samples to your Mac.

Together with a BlueSCSI board, it can also act as a live USB-to-SCSI disk for an E-MU sampler: the sampler sees one of your images as its hard disk while you keep working on the same image on the Mac (see Sampler Link below).

The left pane lists mounted disk images. The right pane shows the selected image or folder contents. The bottom status areas show counts for folders, banks, presets, samples, and disk space.

Mounting Images

  1. Click Mount Image in the toolbar.
  2. Select one or more E-MU disk images, such as .hda files. Hold Cmd or Shift to select several at once.
  3. Each image appears in the left mount list.
  4. Select a mounted image to browse its root folder on the right.
Tip: You can mount multiple images at once, then drag files or folders between them.

Creating a New Image

  1. Choose Tools > New Image… (Shift+Cmd+N).
  2. Pick a size from the presets (8 MB up to 512 GB), or type your own.
  3. The Name field is filled in for you as HD20_<size>.hda and can be edited.
  4. The image is saved in your image folder (default ~/EMU3 Images) and mounted.
  • 512 GB is the largest disk the sampler can address, so it is the maximum.
  • Large images are sparse files: they only take disk space as data is written. The dialog shows the free space of the destination and warns when the volume cannot hold the full size.
  • The image is formatted with the same layout the sampler itself uses, so the sampler shows the full size.
  • Use Settings… (Cmd+,, in the app menu) to choose another image folder, for example on a big disk or a NAS share.

Automatic Mounting

The installer adds a small background helper (emu3linkd) that starts when you log in. It mounts every .hda and .iso image in your image folder as a volume under ~/EMU3 Disks, so the files are always available in Finder (no extra software is needed: macOS mounts them through its own NFS client).

  • The helper keeps running when you quit the app.
  • Change the watched folder in Settings… (Cmd+,).
  • Tools > Mount Image as Volume and Unmount Image Volume do the same for a single image by hand.

Folder Tree

The left pane is a tree. Each mounted image is a top-level item, and its folders are listed below it.

  • Click an image or a folder in the tree to show its contents on the right.
  • Click the small arrow next to an image or folder to expand or collapse it.
  • Right-click in the tree, or use the View menu, to Expand All (⌥⌘=) or Collapse All (⌥⌘−) folders.
  • The tree follows you: when you open a folder on the right, it is highlighted in the tree.
  • New, renamed and deleted folders show up in the tree automatically.

Moving Files with the Tree

  1. Select one or more files in the file list on the right.
  2. Drag them onto an image or a folder in the tree on the left.
  3. Release the mouse button. The files are moved to that folder.
  • Hold Option while dropping to copy instead of move.
  • Dropping on an image in the tree puts the files in that image's top folder.
  • Dropping on a folder in a different mounted image copies the files into that image.
  • Files dragged from Finder onto the tree are imported into the folder you drop on.
  • Dragging folders (not just files) always copies them.
  • Read-only images do not accept drops.

Copying an Image

  1. For a quick copy, hold Option and drag a mounted image row from the left pane to Finder.
  2. Each Option-drag copy gets an increasing number before the extension, such as MyImage_1.hda, MyImage_2.hda, and so on.
  3. You can also Option-drag within the left image pane. The green plus means the numbered copy will be mounted as another image.
  4. To choose the copied image name, right-click the mounted image and choose Copy Image As.
  5. Choose the destination and file name for the copied .hda image.
  6. The app flushes pending image changes before copying so the copy reflects the current mounted image.
Tip: Use Copy Image As before major edits if you want a named backup of the full disk image.

Settings and Tooltips

Open Settings… from the app menu (Cmd+,).

  • Show tooltips: buttons and controls explain themselves when the pointer rests on them. Switch it off here once you know your way around.
  • Image folder: the folder with your disk images. The background helper mounts every .hda and .iso in it, and New Image saves there.

Selecting Items

  • Click an item to select it.
  • Use Cmd+click to add or remove individual files or folders from the selection.
  • Use Shift+click to select a range.
  • The right status area updates to summarize the selected files and folders.

Creating and Organizing Folders

  • Click New Folder in the toolbar to create a folder in the current folder.
  • Right-click a folder and choose New Folder Here to create a folder inside that folder.
  • Right-click a folder and choose Rename Folder to rename it.
  • Folder names are limited by the E-MU filesystem rules.

Importing Files

Import copies E-MU bank files (for example .E4B) from your Mac into the mounted image. The file is added to the folder that is currently open on the right.

  1. Select a mounted image in the left pane and open the folder you want to import into.
  2. Click Import in the toolbar.
  3. Choose one or more files or folders. Hold Cmd to add individual items, or Shift to select a range.
  4. Click Import. The status bar reports how many items were imported and how many failed.
  • Folders are imported together with their contents.
  • Import is not available if the image is read-only. Check that the .hda file is not locked.
  • Imported items change the image file on your Mac. If the image is being served to a sampler, the sampler is told about the change (see Sampler Link).
  • You can also drag files or folders from Finder (see Drag and Drop below).
  • Only E-MU bank data can be imported. WAV files must be converted to an E-MU bank first.

Copy and Paste

  1. Select one or more files in the file list.
  2. Press Cmd+C, or right-click and choose Copy.
  3. Open the destination folder, in the same image or in another mounted image.
  4. Press Cmd+V, or right-click and choose Paste.
  • Pasting inside the same image duplicates the files into the open folder.
  • Pasting into another mounted image imports a copy of the files.
  • Copied files are also placed on the Mac clipboard, so you can paste them into Finder as .E4B files. You can also copy bank files in Finder and paste them here.
  • Paste is disabled for read-only images. Copy works on files only, not on folders.

Delete and Undo

  • Select files or folders and click Delete in the toolbar or menu.
  • Press Forward Delete to delete the selected item.
  • Press Cmd+Backspace to delete the selected item.
  • Press Cmd+Z to undo the last delete.
  • Press Cmd+Shift+Z to redo when available.
Important: Plain Backspace now navigates to the parent folder. Use Forward Delete, toolbar Delete, menu Delete, or Cmd+Backspace when you want to delete.

Exporting

  1. Select one or more bank files.
  2. Click Export, or right-click and choose Export to Mac.
  3. Choose a destination folder on your Mac.
  4. Use Export Samples to extract samples from supported bank files.

Sampler Link: Live Disk for the Sampler

The BlueSCSI board connects to the sampler's SCSI port and to the Mac over USB. Every SCSI read and write of the sampler is passed to the Mac, which reads and writes the image file. The sampler therefore sees an ordinary hard disk, and you can copy banks, samples and CD-ROM images into the same image from the Mac without moving any SD card or cable.

  1. Install the package. The background helper starts at login and serves the image chosen in Tools > Sampler Link (Live USB Disk)… (Cmd+K), even when the app is closed.
  2. Pick the Image and the Access mode (read-write lets the sampler save to it) and press Start Serving. Press Stop Serving to take the disk away from the sampler.
  3. Connect the board with USB and switch the sampler on. The window shows Waiting for the board, Board connected and then Serving to the sampler.
  4. On the sampler, scan the SCSI bus and open the disk.
  • SCSI ID: the disk answers at ID 7 by default. The E64 sampler itself is ID 6. Change the ID in the Sampler Link window (SCSI ID of the board's disk); the sampler needs a rescan afterwards.
  • Working on both sides: the app edits the served image through the helper. While the sampler is busy, Mac changes wait until it is idle, so both sides never write at the same moment.
  • Automatic update on the sampler: after a change on the Mac the board tells the sampler that the disk changed, and presents the disk as removed and re-inserted so the sampler reloads it by itself. If the sampler still shows old contents, re-open the disk on it.
  • Speed: the USB link is full speed (about 0.7 MB/s), so loading a large bank on the sampler takes a few seconds per MB. Copying on the Mac is not limited by it.
  • Log: the window logs when the board connects and when the sampler reads or writes. Right-click the log to Clear Log, Copy Log or Copy Status.

Updating the Board Firmware

  1. Choose Tools > Update Board Firmware… (the last item in the Tools menu).
  2. Choose a .uf2 file in the drop-down. Files found in the firmware build folder, Downloads, Desktop and the installed copy are listed; Other… opens a file picker.
  3. Press Update. The board restarts into its update mode, receives the file and starts again. This takes about 15 seconds, during which the sampler loses its disk.
Important: Do not load or save on the sampler while the firmware is updating. If the update drive never appears, unplug the board, hold the BOOTSEL button while plugging it in, and try again.

Installing and Removing

  • Install EMU3DiskManager.pkg. It installs the app, the background helper (emu3linkd, which serves the sampler disk and mounts images), the volume helper (emu3nfs), the board firmware file and the login agent. In the installer, Customize offers Remove old installs (on by default): it deletes leftovers of earlier versions such as the old per-user login agent and per-user helper copies. Your images and settings are kept.
  • To remove everything, run Uninstall-EMU3.command from /Library/Application Support/EMU3.

Troubleshooting

Cannot Modify an Image

The image may be read-only or locked by the system. Unmount it, check file permissions in Finder, then mount it again.

Drop Does Not Work

Check that the target image is writable and has enough free space. Folder drops preserve the folder contents when copied into another mount.

Status Counts Look Empty

Select the mounted image or folder again. Counts update from the currently mounted filesystem and selected items.

The Sampler Says "Device Not Responding"

Check that the Sampler Link window shows Serving to the sampler or Board connected. If it says Waiting for the board, the board is not visible on USB: check the cable and port. If the board does not appear on the Mac at all, restart the Mac once; a stuck USB port is cleared by that.

The Sampler Does Not See New Banks

Wait a few seconds after the copy finished (the Mac waits for the sampler to be idle first), then re-open the disk on the sampler. A rescan of the SCSI bus also works.

The Background Helper Is Not Running

The log in the Sampler Link window says so. Reinstall the package, or log out and in again.

Cannot Open an Image

Make sure the file is a valid E-MU Emulator III/IV disk image. For BlueSCSI disk image details, visit BlueSCSI Disk Images Documentation.

Basic Workflow

  1. Mount one or more disk images.
  2. Option-drag a mounted image to Finder if you want a backup before editing.
  3. Select a mounted image on the left.
  4. Use double-click, Return, and Backspace to navigate folders.
  5. Use drag and drop to copy files or folders between folders and mounted images.
  6. Use the bottom status areas to confirm folder contents and disk space.
  7. To use the image on a sampler, serve it in Sampler Link and connect the BlueSCSI board.
